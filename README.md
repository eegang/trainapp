# trainapp — Telegram-бот для учёта тренировок

Бот помогает вести дневник: вес, калории, упражнения и сон. Умеет
выгружать отчёт за 30 дней в текстовый файл — его можно скормить GPT для
анализа.

## Возможности

| Кнопка | Что делает |
|---|---|
| Вес на сегодня | Сохраняет текущий вес, ведёт историю |
| Приемы пищи | Суммирует калории за **сегодня** или **вчера** |
| Показатели упражнений | Сохраняет описание тренировки |
| Выгрузить данные за 30 дней | Отправляет .txt-отчёт для анализа в GPT |
| Данные за сегодня | Сводка: вес, калории, упражнения, сон |
| Я сплю / Я проснулся | Таймер сна с подсчётом длительности |

Команды: `/start` — главное меню, `/cancel` — прервать текущее действие.

## Установка

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Файл с токеном
copy .env.example .env        # Windows
# cp .env.example .env        # Linux / macOS

# 3. Впишите в .env токен от @BotFather
#    BOT_TOKEN=123456789:AA...

# 4. Запуск
python main.py
```

## Безопасность токена

Токен **не должен** лежать в коде или попадать в git.

1. Откройте @BotFather → `/mybots` → выберите бота → **API Token** →
   **Revoke current token** (принудительно завершит все сессии).
2. Сгенерируйте новый токен и впишите его в `.env`.
3. `.env` уже в `.gitignore` — в репозиторий он не попадёт.

Если токен когда-либо публиковался, его нужно перевыпустить: Telegram
не скрывает токены от ботов, которые их увидят.

```
trainapp/
├── main.py              точка входа

├── app/
│   ├── bot.py           Bot и Dispatcher
│   ├── keyboards.py     клавиатуры

│   ├── dates.py         работа с датами
│   ├── report.py        сборка отчётов
│   └── handlers/        хендлеры (по фичам)

│   ├── schema.py        создание таблиц
```

## База данных

SQLite, таблицы: `users`, `weight_entries`, `meals`, `exercises`, `sleep`.
Схема создаётся автоматически при первом запуске — файл базы создавать
вручную не нужно.

Резервная копия:

```bash
copy training_bot.db training_bot.db.bak
```

## Зависимости

- `aiogram` — Telegram Bot API
- `aiosqlite` — асинхронный доступ к SQLite
- `python-dotenv` — чтение `.env`
